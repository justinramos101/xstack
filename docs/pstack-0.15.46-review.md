# pstack 0.15.46 adoption review

Reviewed November 20, 2026 against xstack main at `478b738` (0.8.0). The last sync landed October 26 in xstack 0.7.0. It pinned pstack 0.15.32 at `e73df47`. Since that pin, 12 commits touched the upstream `pstack/` directory, through `0b46ec3` on November 19. Both endpoints contain the same 58 top-level skills. The changes affect what those skills do, how they delegate, and which commands they support. ## Take first

- **Review the change the user actually has.** xstack’s default Interrogate review ends at HEAD and gives extra weight to agreement among reviewers. Upstream includes working-tree changes, lets each reviewer try a reproduction in an isolated worktree, and has the lead rerun the command. Port that for behavioral findings. A reviewer can give the command, observed output, and expected result even when they are the only person who spotted the bug. Keep design judgments explicit when a run cannot settle them. [xstack Interrogate](https://github.com/justinramos101/xstack/blob/478b738/src/skills/interrogate/SKILL.md) · [Upstream Interrogate](https://github.com/cursor/plugins/blob/0b46ec399d55/pstack/skills/interrogate/SKILL.md)
- **Give every worker the goal and the acceptance criteria.** Upstream puts shared instructions in `worker.md` and passes them through nested delegations. xstack already bundles helper prompts. Extend them so a replacement worker can recover what the operator asked for, what counts as done, and who can make external decisions. Resolve the file in the worker’s checkout or pass the relevant text to remote workers. Keep the operator’s PR and permission choices authoritative. [Upstream worker instructions](https://github.com/cursor/plugins/blob/0b46ec399d55/pstack/skills/poteto-mode/worker.md) · [xstack Codex runtime](https://github.com/justinramos101/xstack/blob/478b738/src/skills/poteto-mode/references/host-runtime.md)
- **Base PRs on their actual dependencies.** Today Autopilot-stack chains independent PRs together. Upstream lets siblings target trunk and reserves parent branches for genuine dependencies. This avoids restarting unrelated CI after a lower PR changes. Keep the handoff at verified green heads, with the operator controlling the merge. Also take the instructions to push each finished unit and skip a separate verifier for a wording-only follow-up. Preserve xstack’s owner checkpoints. [Upstream Autopilot changes](https://github.com/cursor/plugins/pull/986) · [xstack stack playbook](https://github.com/justinramos101/xstack/blob/478b738/src/skills/poteto-mode/playbooks/autopilot-stack.md) · [xstack owner checkpoints](https://github.com/justinramos101/xstack/pull/43)
- **Take three small skill edits together.** Explain the Number records the decision, the effect that would change it, and the noise floor before a benchmark. Sharpen asks the agent to prototype testable choices and recommend from the result. Ketchup Video burns a readable subtitle below each slide and checks the hold in the rendered file, excluding transitions. xstack already checks reading time and has a file-link fallback. [Measurement and subtitles](https://github.com/cursor/plugins/pull/986) · [Sharpen](https://github.com/cursor/plugins/pull/1236)

## Statechart

**Port the compiler as a breaking change.** xstack already draws Mermaid charts from TLA+, reports invariant failures, and asks the agent to replay failures against the application. Its current CLI also generates a spec from an agreed chart, compares code models with a reference spec or proposed fix, and renders PNGs. Upstream replaces those commands with `statechart SPEC.tla [--config FILE] [--view FILE] [--out DIR]`. Callers that use `from-chart`, `--against`, `--fixed`, `--expect-broken`, or read `stories.md` or `summary.json` need a migration decision. Recommend adopting the upstream interface and documenting each retirement in the release notes. [Fork CLI][fork-cli] · [Compiler replacement][compiler] · [New CLI contract][new-cli]

The compiler checks the supplied config first, removes each broken rule in turn, and reports any rules a bounded rerun could not check. Above 500 states it draws only counterexample paths and omits the chart for a passing model. The CLI publishes `report.md`, TLC output and any chart into a new or empty directory on exits 0 (pass) and 1 (violation). SVG rendering is a separate Pele 1.9.0 step. Keep xstack’s `$statechart` invocation, explicit-invocation metadata and run-local scratch path. Give each rerun its own output directory. [Upstream skill][new-skill] · [Render instructions][render] · [Fork skill][fork-skill] · [Fork metadata][metadata]

Take the compiler at the **final pin**. Follow-up fixes preserve qualified actions such as `C!Up` in temporal counterexamples, wait for macOS to reap the killed worker, report SANY source locations, route arrows through a parent state's border, and parse Windows TLC line endings that could hide a violation. The POSIX launcher selects Node 22.18–22.x or 23.6+, Bun 1.1.5+, or Deno 2+. Native Windows runs the TypeScript entry directly with supported Node and uses a Node janitor for cleanup. xstack’s existing macOS fixture fix handles temp paths and fixtures. Its exclusive mapping-file creation matters only if the old scaffold survives the migration. ### Compiler migration and verification

- **Update the harness with the compiler.** xstack CI already installs Node 24 and checksums TLC 1.7.4. Its download step imports `TLC_TOOL` from a file the port deletes, and both CI and `npm test` select only `.test.mjs`. Wire in the TypeScript suite and its `fast-check@4.5.3` dependency, expose the TLC pin to CI, and keep supplying `TLA2TOOLS` and `JAVA` so the live TLC comparisons run. Exercise the POSIX launcher and direct Node entry on native Windows before claiming platform coverage. [Fork CI][fork-ci] · [Fork test command][fork-tests] · [New tool pin][tools] · [Test package][test-pkg] · [Live TLC oracle][oracle]
- **Update the promises made to users.** The formal-verification generator already tells generated TLA+ skills to invoke `$statechart` by name. Drop its promise to identify which violations a proposed fix resolves, and update the guide, skill catalog and README prerequisites in the same change. The upstream trees for `create-verification-skill`, `maintain-verification-skill` and `maintain-formal-verification-skill` are identical at both pins. [Upstream generator][generator] · [Fork generator][fork-generator] · [Fork guide][guide] · [Catalog][catalog] · [Prerequisites][prereqs] · [Range][range]

**Checks performed.** On macOS, the pinned upstream launcher with real TLC 1.7.4 returned 1 for `CounterInstance` and 0 for `TwoPhaseFixed`. Both charts and reports matched their committed fixtures byte-for-byte. The compiler preserved the full `C!Up` and `C!Back` labels in the failing loop. All 34 tests selected for Windows line endings passed on macOS, including replays of 33 recorded models. The focused CLI checks also passed for qualified action names and worker cleanup after SIGKILL. Native Windows execution and the full upstream suite remain unverified. ## Simplify selectively

- **Make common questions cheaper.** Why goes straight to the commits and PR discussion. How uses one read-only explainer when requested, while build and debug playbooks trace the code directly. Reflect reads its own transcript. Architect sketches two designs and calls Arena for large or contested choices. Trial those defaults while preserving Recall’s ability to follow other sources, Reflect’s Codex transcript and editable-copy handling, and an expressly requested design checkpoint. Update Benny and other callers when changing the How route. Upstream also shortened 14 principle texts, Unslop, Technical Writing, and the PR and Babysit playbooks. Those prose cuts can land separately. [Why, How, and Benny](https://github.com/cursor/plugins/pull/1236) · [Reflect, Architect, and prose cuts](https://github.com/cursor/plugins/pull/1249) · [xstack Reflect](https://github.com/justinramos101/xstack/blob/478b738/src/skills/reflect/SKILL.md)
- **Version the model defaults.** Upstream changed its default coding model to Opus, capped effort at `xhigh`, and moved its Gemini panel seat to Neon at `xhigh`. Keep model names and available effort levels tied to the Codex host. Adopt the migration mechanism for old defaults and retired roles. xstack’s resolver rejects unknown role names, so removing How or Reflect roles without a migration could break even a request for the feature model. Arena can also skip its cross-vendor judge and say why when the session exposes only one vendor. [Routing and migration](https://github.com/cursor/plugins/pull/1249) · [Final Gemini change](https://github.com/cursor/plugins/pull/1284) · [xstack resolver](https://github.com/justinramos101/xstack/blob/478b738/src/skills/setup-xstack/scripts/models.mjs) · [Upstream Arena](https://github.com/cursor/plugins/blob/0b46ec399d55/pstack/skills/arena/SKILL.md)
- **Keep the checked plan and resumable Orchestrate workflow for now.** In 0.15.36 upstream replaced the Orchestrate scripts with host tools. In 0.15.43 it removed the playbook and routed large work to Figure It Out. The same release dropped the plan validator. xstack’s local ledger records which commit passed verification and which PR can land next. Its plan checker catches incomplete verification steps. A shorter default can coexist with those capabilities until there is a tested replacement or an explicit retirement decision. [Orchestrate rewrite](https://github.com/cursor/plugins/pull/1043) · [Final removals](https://github.com/cursor/plugins/pull/1249) · [xstack Orchestrate](https://github.com/justinramos101/xstack/blob/478b738/src/skills/poteto-mode/playbooks/orchestrate.md) · [Plan checker tests](https://github.com/justinramos101/xstack/blob/478b738/scripts/port.test.mjs)
